# 应用启动器 - 使用说明

## 简介
应用启动器是一个 ZTools 插件，用于快速搜索和启动本地 Windows 应用程序。

## 功能特性

1. **智能搜索**
   - 支持 `exe` 或 `app` 关键词触发搜索
   - 优先使用 Everything 进行快速搜索
   - 如果 Everything 不可用，自动切换到目录搜索模式

2. **快速启动**
   - 在搜索结果列表中直接点击即可启动应用
   - 启动后自动关闭 ZTools 主窗口

3. **历史记录**
   - 自动记录最近启动的应用
   - 当搜索结果为空或关键词为空时，显示最近启动的应用
   - 最多保存 20 条历史记录

## 使用方法

### 搜索应用
在 ZTools 主界面输入：
- `exe music` - 搜索包含 "music" 的应用
- `app chrome` - 搜索包含 "chrome" 的应用

### 查看最近启动的应用
在 ZTools 主界面输入：
- `exe` 或 `app` - 显示最近启动的应用列表

### 启动应用
1. 在搜索结果列表中选择目标应用
2. 点击或按回车键启动应用
3. 应用启动后，ZTools 主窗口会自动关闭

## 依赖项

### Everything 命令行工具（推荐用于快速搜索）

**重要说明**：`es.exe` 不包含在 Everything SDK 中，它是一个独立的工具。

1. **下载 Everything 主程序**：https://www.voidtools.com/zh-cn/downloads/
   - 安装并运行 Everything（必须在后台运行）
   - es.exe 需要通过 IPC 与 Everything 主程序通信

2. **下载 es.exe（命令行工具）**：https://www.voidtools.com/zh-cn/downloads/#cli
   - 找到"命令行界面"部分
   - 64位版本：https://www.voidtools.com/ES-1.1.0.30.x64.zip (67 KB)
   - 32位版本：https://www.voidtools.com/ES-1.1.0.30.x86.zip (56 KB)

3. **解压并放置 es.exe**：
   将 `es.exe` 放置在以下任意位置之一：
   - `C:\Program Files\Everything\es.exe`
   - `C:\Program Files (x86)\Everything\es.exe`
   - 插件目录：`app-launcher/es.exe`
   - 用户主目录：`es.exe`
   - 您的自定义路径：例如 `E:\_other\下载\Everything-SDK\es.exe`

4. **测试 es.exe**：
   打开命令提示符，输入：
   ```cmd
   es.exe *.exe
   ```
   如果能显示文件列表，说明配置成功。

### 备用搜索方法
如果未找到 `es.exe`，插件将使用目录搜索（速度较慢）：
- 搜索常见应用目录：`Program Files`、`Program Files (x86)`、开始菜单等

### Node.js 依赖
- `iconv-lite`: 用于正确解码 Windows 系统中的文件名（可选）

## 工作原理

1. 当用户输入搜索关键词时，插件会：
   - 如果关键词为空，返回最近启动的应用列表
   - 如果关键词不为空，尝试使用 Everything 搜索
   - 如果 Everything 不可用或搜索无结果，使用目录搜索作为备用方案
   - 如果仍然没有结果，返回最近启动的应用列表

2. 当用户启动应用时：
   - 将应用路径添加到历史记录
   - 使用 Windows `start` 命令启动应用
   - 关闭 ZTools 主窗口

## 注意事项

1. 首次使用时，历史记录列表为空
2. 支持的可执行文件类型：`.exe`, `.bat`, `.cmd`, `.lnk`
3. 搜索结果数量取决于 Everything 或目录搜索的返回结果
4. 历史记录存储在 `preload/app-history.json` 文件中

## 故障排除

### 问题：搜索不到应用
**解决方案**：
- 确保 Everything 已安装并运行
- 检查 Everything 是否已建立索引
- 尝试直接在 Everything 中搜索确认文件存在

### 问题：启动应用失败
**解决方案**：
- 检查应用路径是否正确
- 确保应用程序未被移动或删除
- 尝试手动启动应用程序确认是否可运行

### 问题：历史记录丢失
**解决方案**：
- 确保 `preload/app-history.json` 文件存在
- 检查文件权限是否正确
- 历史记录会在下次启动应用时重新生成
